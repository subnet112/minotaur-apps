# Phase 12.5 — Hybrid Component Rebase Spec

**Date:** 2026-05-25
**Status:** Approved by user; dispatching implementation
**Path:** C (hybrid rebase)
**Branch:** `feat/dex-design-consolidation`

---

## Goal

Achieve **100% functional parity** with the old unstyled swap app (preserved in `archive/frontend-swap/components/`) while keeping the design's JSX/CSS contract. No mock data in production paths. Every behavior the old app supported must be reachable in the new app.

## Approach

**Hybrid rebase** — for each design component, choose one of two paths:

- **Keep Verbatim (KV):** simple chrome / display-only with already-correct prop interface.
- **Rewrite (RW):** interactive component that hardcoded mock data. New version uses design's JSX+CSS but the old archive's behavior + props from real store.

## Implementation order

Smallest-first to lock the pattern; SwapForm last because it depends on everything.

| # | Pass | Subagent | What |
|---|---|---|---|
| 1 | types.ts cleanup + `ActionButton` RW | A | Delete mock constants, rename types, rewrite simplest component. |
| 2 | `SettingsSheet` + `OrderStatusCard` RW | B | Wire settings to store, wire order card to real activeOrder. |
| 3 | `WalletButton` address prop + `RevealPanel` RW | C | Real address truncation, history from store, debug from store. |
| 4 | `TokenSelectorModal` RW | D | Real tokens prop + ethers custom-token-import. |
| 5 | `SwapForm` RW | E | Amount input, MAX, swap direction, recipient (MetaMask + manual), chain selector. |
| 6 | Verification + visual regression | local | Re-capture baselines (cropped), zero-drift target. |

Each pass:
1. Implementation subagent makes the changes + commits.
2. Independent verification (pagewire snap + unit tests + typecheck).
3. Mark complete; move to next.

## Architecture invariants (must hold after every pass)

- Data flow: store → selectors → SwapPage → components. No upward closures.
- Every store action exists; every action is invoked somewhere.
- No `as any` casts that mask missing prop wiring.
- No `MOCK_*` constants referenced from `src/components/*.tsx` or `src/pages/*.tsx`.
- `pnpm typecheck` clean; `pnpm test:unit` 100% pass.
- Pagewire snap shows expected elements at `/swap`.

## Acceptance criteria

1. Zero `MOCK_*` constant references outside of `archive/`.
2. All 21 audit gaps closed (every ❌ and ⚠️ from `2026-05-25-dex-design-consolidation-design.md` §Phase 12.6 maps to a fix).
3. Unit tests: 54+ passing (existing 54 stay green; new tests for any new code).
4. Pagewire E2E: 3/3 scripts pass.
5. Manual smoke: connect MetaMask → set amount → quote arrives → action button transitions → click → toast fires.
6. Visual regression: revisited after cropping baselines to swap-surface only (no platform chrome).
